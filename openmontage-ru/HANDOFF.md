# Передача работы: монтаж Reels на ПК владельца (RTX 5080)

Этот файл — всё, что нужно новой сессии Claude, чтобы продолжить монтаж с
того же места. Читать целиком перед работой.

## Правила владельца (обязательно)

- **Никаких автопроверок, фоновых задач и расписаний**, которые тратят токены
  без команды. Разовые проверки — только по прямой просьбе.
- **После каждого ролика спрашивать, всё ли устраивает**, и только после
  ответа переходить к следующему.
- Ролик **не длиннее 30 секунд**, последнее слово не обрезать (хвост ≥ 0.3 с).
- **Голос всегда в приоритете**: эффекты не глушат речь (замер в finish, запас
  ≥ 12 дБ). **Глитч-звуки запрещены** (конвейер сам их выкидывает).
- **Мат вырезать** (брать чистые дубли или склеивать вокруг).
- **Шрифт субтитров не менять** (капитель 81px, тёмный ореол, позиция 0.679).
- Титр — Rimma Sans Bold, первая строка красная `#FD3233`, первая строка
  заметно крупнее второй (соотношение ≈ 0.72); под титром субтитров нет.
- Цвет — v5 (мягче, резче, без виньетки). Качество в приоритете.
- Динамика: **резкие наезды/отъезды** камеры на ударных словах (`keys` с
  `"punch"`), в каждом куске.
- Стиль графики (одобрен на роликах 6–7, «вот это прям круто»):
  **редакционные карточки** — `stack` (тёмное стекло слева, красный заголовок,
  пункты ✕/✓ выезжают по словам), `stamp` (красный штамп с ударом), `label`
  (ярлык + заголовок), `cta` (светящаяся красная рамка), «видео в карточке»
  (`cards` в спеке). Старые стеклянные плашки по центру (`list`, `pop`,
  `strike`) владельцу не нравятся — не использовать.

## Установка (один раз)

PowerShell в любой папке:

```powershell
powershell -ExecutionPolicy Bypass -File setup_windows.ps1
```

Скрипт ставит Git, Python 3.11, Node.js, FFmpeg с NVENC, клонирует этот
репозиторий и OpenMontage (коммит `08e2151`) в `%USERPROFILE%\Reels`,
ставит Whisper с CUDA-библиотеками, Remotion, шрифты и патч. В конце
печатает проверку: имя видеокарты, наличие NVENC, число CUDA-устройств.

## Запуск

```powershell
$Py = "$env:USERPROFILE\Reels\OpenMontage\.venv\Scripts\python.exe"
$K  = "$env:USERPROFILE\Reels\content_plan_dashboard\openmontage-ru\reels"

& $Py $K\take_split.py source.mp4 -o takes.json          # расшифровка по дублям
& $Py $K\montage.py spec.json --gpu on --max-mb 0         # весь монтаж
& $Py $K\montage.py spec.json --from render --gpu on      # переиграть с этапа
```

- `--gpu on`: Whisper на CUDA (float16), промежуточные файлы h264_nvenc,
  итог hevc_nvenc p7. Если Whisper на видеокарте не стартует — сам
  откатывается на процессор и пишет почему. `--gpu auto` — по умолчанию.
- `--max-mb 0`: без лимита размера (дома файл не пересылается в чат) —
  итог один проход с качеством `-cq 16`.
- Исходники брать **в оригинальном 4K** с диска, а не 720p из Google Drive.
  Итог всё равно 1080×1920; 4K даёт заметно более чёткую картинку.

## Порядок работы над роликом

1. `take_split.py` → посмотреть дубли, выбрать лучшие, без мата, ≤ 30 с.
2. Спека `spec_NN.json` (примеры: `reels/specs/spec_06.json`,
   `spec_07.json` — новый стиль). Куски `a/b` в секундах исходника.
3. `montage.py --only assemble/grade/words` → **распознать каждый кусок
   отдельно** (cut_XX.mov) и проверить, что слова целы. Концы слов часто
   режутся — смотреть энергию голоса (highpass 200 Гц, окна 30–50 мс) и
   сдвигать границы. Хвост ролика ≥ 0.3 с.
4. По `out/segments.json` расставить вставки и звуки на слова.
5. `--from render`, посмотреть кадры, отправить, **спросить владельца**.

## Замечания по коду

- Проверка субтитров (`caption_spec`) даёт ложные срабатывания на Щ/Ш/Й,
  стаканах, руках и плашках — смотреть кадр глазами.
- Шрифты Oswald/Inter в `fonts/` — кириллические сабсеты; цифры и знаки
  берутся из `*-latin.woff2` (подхватываются сами).
- `graded.mov` → `carded.mov` (если в спеке `cards`) → Remotion.
