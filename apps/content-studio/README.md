# Content Studio — Serbolin

Отдельный исходный раздел закрытой личной контент-студии Эдуарда Серболина. Рабочая версия размещается на Manus по адресу [fitstrategy-nbvz849p.manus.space](https://fitstrategy-nbvz849p.manus.space/).

Приложение построено как защищённый full-stack проект: вход через Manus OAuth, постоянные персональные данные в базе, tRPC API и React-интерфейс. Первый релиз включает разделы «Идеи», «Студия», «План / календарь», «Библиотека», «Голос и ЦА» и «Аналитика». Генерация ИИ и внешние публикации намеренно отложены.

| Команда | Назначение |
|---|---|
| `pnpm install` | Установить зависимости |
| `pnpm dev` | Запустить среду разработки |
| `pnpm test` | Выполнить проверки клиентской, общей и серверной логики |
| `pnpm check` | Проверить типы TypeScript |
| `pnpm build` | Собрать production-версию |

> В этом разделе хранится синхронизированный исходный код. Публикация и переменные окружения управляются проектом Manus, а не локальным запуском репозитория.
